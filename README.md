## 运行条件

- Windows x64、已登录的 Steam、本机《以撒的结合：忏悔+》与 tModLoader。
- 当前兼容组合：以撒 Repentance+ 1.9.7.17、Terraria 1.4.4.9、tModLoader 2026.08.3.0、.NET 8 x64。
- 首次安装前分别启动一次以撒和 tModLoader 到主菜单，然后保存并完全关闭以撒。安装时会检测路径和运行环境；无需另外安装 Python。

完整包不包含完整 Terraria 引擎或私人存档。首次设置从玩家本机准备隔离引擎，不改变原 Terraria 人物及用户 tModLoader 模组组合。

## 安装与使用

1. 按上表选择一个下载包，完整解压到普通文件夹。
2. 双击对应安装入口，按提示完成一次设置。通常会自动识别游戏位置；存在多个有效目录时需选择。完整包会优先使用已完整下载的 TBOT 工坊版本，避免重复安装。
3. 完成后直接从 Steam 启动以撒，在 Mods 菜单启用 TBOT。首次后台初始化请在主菜单稍等。
4. 选择“泰拉瑞亚”角色开始游戏，存档 1、2、3 均可用。

首次设置会安装当前 Windows 用户的登录助手，本次立即运行。助手在以撒实际加载 TBOT 后启动隔离后台，禁用 TBOT 或退出游戏后停止后台。配置及进度保存在本地应用数据的 `TBOT` 目录；此目录也提供关闭、启用登录助手及查看状态入口。关闭助手会暂停自动桥接，保留进度。

| 操作 | 按键 |
| --- | --- |
| 移动 | WASD |
| 瞄准、使用武器 | 鼠标、左键 |
| 武器自身右键能力 | 右键 |
| 背包 | I |
| 快捷栏 | 1～0 |
| 装备配置 | F1～F3 |
| 暂停 | Esc |

默认外观为 `issac`。新局快捷栏：1 铜短剑、2 天顶剑、3 泰拉刃、4 普通永夜刃、5 彩虹猫之刃。继续局保留当局库存，不重复赠送。

## 后续更新

工坊玩家的普通模组及后台代码更新由 Steam 下载，保存关闭并重新启动后应用。已安装的 Python 环境身份匹配时继续复用；环境变更或损坏时按提示下载对应首次设置包。

GitHub 本地版玩家下载新版本完整包，关闭以撒后运行新版 `一键安装.cmd`，使用原运行目录即可保留库存和进度。请勿使用旧分享版卸载器清除新的安装数据。
