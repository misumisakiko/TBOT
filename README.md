## 安装与升级

需要 Windows 64 位、已登录的 Steam，以及本机安装的以撒和 **tModLoader**。当前验证组合为 Repentance+ 1.9.7.17、tModLoader 2026.08.3.0 / Terraria 1.4.4.9 / .NET 8 x64，无需另装 Python。

1. 首次安装前，分别打开一次以撒和 tModLoader 到主菜单，再保存并完全关闭以撒。
2. 完整解压下载包，运行对应安装入口，按提示完成一次设置。
3. 以后从 Steam 正常启动以撒，在 Mods 菜单启用 TBOT，并在主菜单等待后台准备完成。
4. 选择“泰拉瑞亚”角色。三个存档槽位分别保存进度；我的真实开发测试仅使用存档 3。

首次设置准备隔离引擎并登记当前用户的登录助手，不生成桌面快捷方式。启用 TBOT 时自动启动后台，禁用或退出后停止；原 Terraria 人物及用户 tModLoader 模组组合保持。下载包不含完整游戏引擎或私人存档。

GitHub 本地版升级时关闭游戏后运行新版完整包。工坊玩家先等待 Steam 完整下载新版，重启游戏后应用；首次设置环境匹配时复用，损坏或变更时按提示重做。完整包会优先识别已有完整工坊订阅，避免重复安装，因此订阅玩家应先确认工坊内容也已更新。

**从此前已发布的 0.6.7 升级，旧对局需要手动新开一局。** 旧格式不迁移，旧存档与检查点保留，不会自动删除或重开。已使用本次武器／资源框架创建的兼容对局可继续保留库存、生命和装备；新局才发放五把初始武器。

使用“三只熊中文控制台”时，请同时订阅并启用 [TBOT三只熊兼容补丁](https://steamcommunity.com/sharedfiles/filedetails/?id=3822895875)。补丁独立提供，不修改三只熊原文件。

## 0.6.8 更新

这次更新中，我扩展了武器与资源使用范围，并接入原生防具、套装和饰品能力。

- 扩展原生使用入口：近战、弓枪、魔法、召唤／鞭、爆炸物及攻击型工具；弹药、魔力、召唤数量遵循 Terraria 原生规则。
- 接入生命水晶、生命果、魔力水晶，以及治疗／回魔药水和原生冷却；库存消耗采用数量增量同步。
- 防具、套装与饰品通过原生装备生命周期计算伤害、暴击、攻速、防御、移速和防击退，不在 Lua 复刻装备数值表。
- 接入克苏鲁之盾／日耀冲刺、额外跳跃和翅膀飞行，以及日耀护盾、蜜蜂与星星斗篷衍生弹幕等代表能力。
- 修复星尘护卫重复生成与重影、旧鼠标采样导致的延迟左键，以及已捕获的覆盖层弹幕绘制故障。
- 神圣护佑改用一次性原生凭据处理通信延迟，确认后由原生消耗 Buff 并进入冷却；本次专项修复已通过隔离验证，真实以撒仍待复测。

既有旅行研究／复制、分类、英文搜索和 Ctrl+V 粘贴中文名称保留；继续支持卡牌、炸弹、流程门、通关宝箱，以及对应工具破坏岩石、近战破坏大便／红火／爆桶和推动巨魔炸弹。

新局五把武器：铜短剑、天顶剑、泰拉刃、普通永夜刃、彩虹猫之刃。

## 验证与限制

我已确认指定测试组中除神圣套组外的项目通过，以及星尘护卫、延迟鼠标和覆盖层问题的修复。最新神圣护佑修复已完成 C# 编译、17 项 Lua 回放和 7 项隔离原生引擎与 Lua 收发检查，包含合计 70ms 注入延迟；**这不等于真实以撒受击已通过**，该项仍待存档 3 复测。

我没有遍历所有装备或重跑全部武器。其他装备的自然面板加成不代表其特殊效果全部支持；其他电脑、真实工坊订阅更新与前台性能仍需确认，不宣称所有场景稳定 60 FPS。

未开放完整 Terraria 世界、建造、钓鱼、捕虫、油漆、多人、模组装备或旅行无敌／时间／天气控制。未适配用途允许复制和存放，但使用被静默拦截。持物在有效背包 UI 外左键丢弃按销毁处理；暂停和切后台不销毁。

遇到问题请附版本、完整报错与复现步骤；分享日志前移除私人路径及账号信息。运行日志可在本机 TBOT 数据目录的 `artifacts/native-link` 和 `assistant` 下找到；通过已登记的 `%LOCALAPPDATA%\TBOT` 入口查看，应用容器安装的实际目录以本机安装记录为准。

暂停使用时，在游戏 Mods 菜单禁用 TBOT 并退出游戏，后台引擎会停止；如不再需要工坊版，可取消订阅。保留本机 TBOT 数据目录即可保留库存和进度，清理前请自行备份，不要使用旧版卸载器删除当前运行数据。
