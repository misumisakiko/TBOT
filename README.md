![TBOT 封面](workshop-preview.png)

## 安装与使用

需要 Windows 64 位、已登录的 Steam，以及本机安装的以撒和 **tModLoader**。当前验证组合为 Repentance+ 1.9.7.17、tModLoader 2026.08.3.0 / Terraria 1.4.4.9 / .NET 8 x64，无需另外安装 Python。

1. 首次安装前，分别打开一次以撒和 tModLoader 到主菜单，然后保存并完全关闭以撒。
2. 完整解压所选下载包，运行对应安装入口，按提示完成一次设置。
3. 以后直接从 Steam 启动以撒，在 Mods 菜单启用 TBOT，在主菜单等待后台准备完成。
4. 选择“泰拉瑞亚”角色开始游戏，存档 1、2、3 均可用。

首次设置会准备隔离引擎并登记当前用户的登录助手，不生成桌面启动快捷方式。以撒启用 TBOT 时自动启动后台，禁用或退出后停止；原 Terraria 人物和用户 tModLoader 模组组合保持。下载包不含完整游戏引擎或私人存档。

使用“三只熊中文控制台”时，请同时订阅并启用 [TBOT三只熊兼容补丁](https://steamcommunity.com/sharedfiles/filedetails/?id=3822895875)。补丁独立提供，不修改三只熊原文件。

## 已实现功能与 0.6.7 更新

- 三个存档槽位独立角色进度；原生角色、装备外观、背包、快捷栏、说明框与翅膀飞行。
- 原版近战武器及其攻击、弹幕、动画、音效和武器自带的格挡、招架、吸血、持续伤害等效果。
- 规范化旅行角色模板，默认解锁全部原版可研究物品；原生研究／复制面板支持分类、英文搜索及 Ctrl+V 粘贴中文名称。
- 起步直接达到当前配置移速；滚轮及点击快捷栏切换物品。
- 卡牌、炸弹、普通与特殊流程门、通关宝箱等交互；近战可破坏大便、红色火堆、爆桶，并推动巨魔炸弹类实体。
- 新局五把武器：铜短剑、天顶剑、泰拉刃、普通永夜刃、彩虹猫之刃。继续局保留库存、装备、生命和任务进度，不重复发放。

远程、魔法、物块等未适配物品允许复制和存放，暂不能使用；不开放旅行无敌、时间、天气控制。持物在背包有效 UI 外左键丢弃按销毁处理，暂停或切后台不会销毁。

| 操作 | 按键 |
| --- | --- |
| 移动 | WASD |
| 瞄准、攻击 | 鼠标、左键 |
| 武器自身右键能力 | 右键 |

| 快捷栏 | 1～0、滚轮、点击快捷栏 |
| 装备配置 | F1～F3 |

## 更新与验证范围

GitHub 本地版玩家保存并完全关闭以撒后，运行新版完整包的 `一键安装.cmd`；沿用原运行目录，保留进度。工坊玩家由 Steam 下载模组及匹配后台，关闭并重新启动游戏后应用；首次设置环境匹配时复用，环境变更或损坏时按提示重做。旧版自启助手未正常运行的玩家可关闭游戏后重新运行新版首次设置。不要使用旧分享版卸载器删除当前运行数据。

0.6.7 已在作者本机存档 3 测试并获确认；原生研究复制、输入与物理交互等新增路径完成定向检查，稳定武器结果复用。其他电脑、真实工坊订阅更新仍需后续验收；不宣称全部场景稳定 60 FPS。遇到问题请附版本、完整报错和复现步骤，分享日志前移除私人路径及账号信息。

Steam 主工坊条目：[TBOT](https://steamcommunity.com/sharedfiles/filedetails/?id=3819700056)。工坊更新由作者手动上传，与 GitHub 发布时间分别记录。
